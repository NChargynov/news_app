# Montserrat

Шрифт используется для воспроизведения типографики экрана Explore из Figma.

- Источник: [Google Fonts — Montserrat](https://github.com/google/fonts/tree/main/ofl/montserrat).
- Файл: `Montserrat-Variable.ttf`, оригинальное имя — `Montserrat[wght].ttf`.
- Лицензия: SIL Open Font License 1.1, полный текст находится в `OFL.txt`.
- Используемые насыщенности: 300, 400, 500 и 700.

Шрифт включён в ресурсы приложения и не требует загрузки при запуске.
